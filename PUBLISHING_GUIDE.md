## Local preview
Open `index.html` in a browser.

## Publishing
Recommended: GitHub Pages.

1. Create a public GitHub repository named `<your-github-username>.github.io`.
2. Upload all files from this folder to the repository root.
3. In GitHub: Settings → Pages → deploy from the `main` branch.
4. Your live address will be `https://<your-github-username>.github.io/`.

## Google Search
After the site is live:
1. Open Google Search Console: https://search.google.com/search-console
2. Add and verify the site/domain.
3. Submit `sitemap.xml`.
4. Use URL Inspection → Request Indexing for the homepage.

A site being live does not guarantee immediate Google indexing. Search Console is used to request indexing and monitor search visibility.

## Custom domain
A custom domain such as `sajidnasim.com` can be connected later. Once the final domain is selected, update:
- canonical URL
- `sitemap.xml`
- `robots.txt`
- Open Graph URL
